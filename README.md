## 👋 About me

I'm **Reinaldo**, 29, a **Senior Software Engineer at BTG Pactual**. I build web, mobile and backend systems for the financial market.

I've worked across a lot of technologies, but the **JavaScript/TypeScript ecosystem** is where I feel most at home: React and Next.js on the front, Node.js and NestJS on the back, TypeScript end to end. I also care about product and UI/UX, so I like owning a feature from the design to production.
