## 👋 About me

I'm **Reinaldo**, a **Senior Software Engineer at BTG Pactual**, working on the Investor Relations platform: APIs with .NET and PostgreSQL, deploys on Azure, AWS integrations, scheduled jobs and real-time communication with WebSockets — and React with a micro frontend architecture (single-spa) on the front.

Before that I built serverless, decoupled services with Node.js and AWS Lambda at **CI&T**, and led development teams at **Okalab**, **Prevlife** and **Imobpower**, mentoring junior devs and making architecture decisions.

Most of my day is **TypeScript**, but I'm comfortable with Java, Python, C# and Go. I value Clean Code, SOLID and automated tests, and I like owning a feature from design to production.

🌐 More about me and my projects: **[reinaldo-silva.github.io](https://reinaldo-silva.github.io)**
